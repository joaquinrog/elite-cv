# Roadmap

The current prototype proves a local source-to-PDF vertical slice. Future
versions are candidates, not commitments.

## v0.1

- Provenance-linked structured profile and variants.
- Deterministic LaTeX/PDF build, extraction, preview, reports, and manifest.
- Local-only defaults for private sources and generated artifacts.
- Thin CLI, manual workflow, agent instructions, and public safety guardrails.
- External pilot evidence before a tagged release.

## v0.2 candidates

Only after pilot blockers are measured:

- Guided terminal review.
- JSON Resume import/export with provenance-preserving extensions.
- Job-description targeting without predictive ATS scores.
- Variant diffs and evidence freshness checks.
- Stable package installation through `pipx` or `uvx`.

## v0.3 candidates

Only after repeated usage justifies the interface:

- Local-first visual review.
- Provenance graph exploration.
- Tested import adapters and local-model intake.
- Redacted recruiter review bundles.

The project will not add a hosted database, broad theme marketplace, automatic
LinkedIn scraping, or a web editor merely to increase surface area.
