# Adoption And Launch

No telemetry is enabled by default. Product evidence is collected through
opt-in feedback, consent-based case studies, public issues, or anonymous
aggregate timing supplied voluntarily.

## Activation definition

An external user is activated after producing a share-ready PDF, inspecting the
evidence report, and completing the release checklist without the maintainer
editing their profile data or generated LaTeX.

## v0.1 pilot instrument

With consent, record:

- Time to first valid personal draft and time to release.
- Direct maintainer edits required.
- Conflicts caught and build failures.
- Agent used, if any, and documentation blockers.
- Evidence-report usefulness.
- A later variant or profile update.

Do not request CV contents, raw sources, credentials, or private employer data.
Publish only aggregate results or explicitly approved case studies.

## Launch waves

1. Design partners in the initial technical audience.
2. Technical release after tests, history review, and documentation audit.
3. Evidence-based follow-up only after measured activation and retention.

Five external activations, three independent users, three returning users, and
no unresolved high-severity privacy incident are promotion gates, not current
facts.
